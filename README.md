# lili's film

A photobooth web app that captures 4 photos with a 5-second countdown, generates a customisable photo strip, and lets you download it as an image or a live video.

## Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later)
- npm (comes with Node.js)

## Getting Started

1. Clone the repo and install dependencies:

```bash
git clone <your-repo-url>
cd photobooth
npm install
```

2. Run the development server:

```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Usage

- Allow camera access when prompted
- Click "start session" to begin the 5-second countdown
- 4 photos are captured automatically
- Customise your strip with filters and colours
- Download as a photo strip (PNG) or a live video (MP4/WebM)

## Tech Stack

- Next.js 16
- React 19
